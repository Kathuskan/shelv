# Shelv logo

`shelv-symbol-shelf.png` is the selected shelf symbol, copied from the supplied `output/logos/shelv-symbol-shelf.png`.

`shelv-logo.svg` combines that symbol with the existing lowercase Shelv wordmark. It embeds the source image and can be used independently of the app. The website keeps the wordmark as live text and displays the symbol beside it, with the existing “books find a home” tagline.

The symbol uses the same `#4f427c` ink as the wordmark. An SVG filter masks the source’s white background and applies the inherited text colour while preserving the original shelf silhouette and PNG.
